# PWCLI scientific illustration style guide

Accuracy and readability always outrank decoration. Never change raw values, labels, method order, scope, or causal direction.

## Diagrams

- Establish one dominant reading direction and no more than three hierarchy levels.
- Group repeated modules consistently; use a restrained, color-blind-safe palette.
- Keep shapes, arrows, borders, corner radii, icons, and spacing systematic.
- Separate training-only, inference-only, optional, and iterative paths structurally.
- Prefer short exact labels. Exclude the figure title and caption from the canvas.

## Statistical plots

- Bars use a thin dark edge; error bars have visible caps. Lines use distinct markers as well as color.
- Scatter plots retain observations. Heatmaps use square cells and legible values when density permits.
- Donut charts use white separators and only represent true part-to-whole data.
- Legends never cover evidence. Grids remain subordinate. Axes include supplied units.
- Avoid 3D unless a real third dimension exists. Never invent interpolation, uncertainty, or labels.

## Quality gate

Check overlaps, clipping, tiny text, alignment, ambiguous arrows, redundant legends, and excessive whitespace. A visually attractive but unfaithful figure fails.
